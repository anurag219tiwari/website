Portfolio Tracker

A private application for tracking personal finances, investments, and transactions.

About

Portfolio Tracker is a personal financial tracking application used to organize investment and transaction records.

Google account access

The application may connect to the owner's Gmail account to retrieve financial transaction alert emails needed for automated transaction tracking.

Gmail access is read-only. The application does not send, delete, modify, or manage emails.

Privacy

This application is intended for personal use. Information accessed through connected Google services is used only for the application's personal financial tracking functionality and is not sold or shared for advertising.
