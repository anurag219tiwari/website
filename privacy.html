Privacy Policy

Portfolio Tracker · Last updated: October 1, 2026

1. Overview

Portfolio Tracker is a personal-use application for tracking personal finances, investments, and transactions. This privacy policy explains how information accessed by the application is used.

2. Google Gmail data

With the user's authorization, Portfolio Tracker may access Gmail messages using Google's Gmail API. The application requests read-only Gmail access.

The application uses this access to retrieve relevant financial transaction alert emails and extract transaction information for personal financial tracking.

3. What the application does not do

  • It does not send emails.
  • It does not delete or modify emails.
  • It does not sell Gmail data.
  • It does not use Gmail data for advertising.
  • It does not share Gmail data with third parties for their own purposes.

4. Data use and storage

Information retrieved from Gmail is used only to provide the application's personal transaction-tracking functionality. Relevant transaction information may be stored by the application as part of the user's personal financial records.

5. Data security

The application is intended for personal use. OAuth credentials and application data should be stored securely by the user and should not be committed to a public source-code repository.

6. Third-party services

The application uses Google APIs to access Gmail when authorized by the user. Google's own terms and privacy practices apply to Google's services.

7. Changes to this policy

This policy may be updated when the application's functionality changes. The date at the top of this page indicates the latest update.

8. Contact

For questions about this personal-use application, contact the application owner through the contact information associated with the Google Cloud project.
